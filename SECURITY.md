# Security and responsible use

This is an experimental static-analysis and evaluation tool, not a security certification. Use it on stable local files you control. Do not use reports as the sole basis for a safety or deployment decision.

For a suspected sensitive issue, contact the maintainer through the profile linked from the repository rather than posting secrets in a public issue. Never include access tokens, private source, account data, or employer/client material in an issue or pull request.

No versions currently have a commercial support or security-response guarantee.
